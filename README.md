# Portfolio Website

Website portfolio pribadi bertema **indigo gelap**, dibuat dengan HTML, CSS, dan JavaScript.
Dilengkapi popup kontak yang berisi WhatsApp, Email, Instagram, GitHub, dan LinkedIn.

## Fitur

- **Navbar sticky** dengan menu yang otomatis menandai section yang sedang dilihat (scrollspy)
- **Responsive**, nyaman dibuka di HP, tablet, dan laptop
- **Popup kontak** setelah klik tombol *Contact Me*:
  - WhatsApp, Email, Instagram, GitHub, dan LinkedIn
  - Bisa ditutup dengan tombol ×, klik area gelap, atau tombol `Esc`
- **Section lengkap**: Home, About, Project, dan Contact
- **Card project** dengan efek hover
- **Tema warna** mudah diganti lewat variabel CSS

## Teknologi

| Teknologi | Kegunaan |
|---|---|
| HTML5 | Struktur halaman |
| CSS3 | Styling kustom (`css/style.css`) di atas Bootstrap |
| JavaScript + jQuery | Popup kontak dan interaksi (`js/script.js`) |
| Bootstrap 4.6.2 | Grid, navbar, dan komponen modal |
| Google Fonts | Plus Jakarta Sans |
